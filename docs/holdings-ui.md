# Holdings UI

更新：2026-10-26。本文件是独立持仓表的唯一UI规范；[ui.md](ui.md) 是总入口。账户刷新、价格来源、会计、Days与P/L Day计算只在 [holdings-data.md](holdings-data.md) 维护，图案与操作含义见 [Logo / Icon](ui.md#logo--icon)。产品界面仅使用英文。

## 位置、折叠与宽度

- Monitor 的 Holdings 固定在 List 面板顶部、Focus 上方，位于下方名单的纵向滚动区域之外。滚动 Focus 时，持仓表、账户总值和 Total 均留在顶部。右上角仅显示整数总值数字，不显示小数或总值 title；悬停现金与来源说明保留。
- 最后成功账户刷新时间`fetched_at`落后当前时间不足一分钟时隐藏；达到一分钟才显示原时间，位于总值左侧、底部对齐，悬停包含完整成功更新时间/positions时间或失败原因。比较账户刷新时间，不使用动态行情时间。成功刷新后自动隐藏；断开WS后仍复用页面现有秒级时钟更新显隐，不新增请求或定时器。首次尚无成功数据仍显示Loading或失败状态。
- Holdings 按内容使用自然高度，不增加独立纵向滚动或最大高度限制。展开时 Total 下方与常规 List 列头之间保留8px空白；折叠时取消该空白。整体折叠后释放空间给下方名单，折叠选择本地记忆；保留既有 Buy/Sold 明细展开。表格过宽时保留水平 overflow。
- Holdings 是独立只读表。主行按买入 sequence 展示，同 ticker 的不同批次保留；常规 List 在前端屏蔽持仓已有 ticker，后端归属仍独立；不参与名单勾选、增删、拖动、Tag 筛选或 Shift 重排。
- 持仓自然内容宽度只在必要时提高 Monitor List 的最小宽度，默认占比和共用最小宽度仍以 [List UI / 宽度与视觉](ui.md#宽度与视觉) 为准，不把默认比例改成固定内容宽度。报价更新不能让侧栏反复缩窄或抖动；展开明细需要更多宽度时增长，收起不引起宽度抖动。
- 计数外观使用 [List UI](ui.md#宽度与视觉) 的共用 count-badge。整体折叠、交易明细和排序图形遵循 [Logo / Icon](ui.md#操作与状态图标)。

## 列与格式

列为 **Symbol、Net Liq、Days、P/L %、P/L、Sold、Chg%、Ext、P/L Day**；当前Regular启用 [Intraday State](intraday-state.md) 时在右侧增加ADR、CumVol、LocalVol，其他时刻整组隐藏。余仓主行从Symbol至ADR的全部非量能字段构成连续价格／财务胶囊，保持现有列顺序；CumVol、LocalVol独立使用各自灰阶胶囊。共用[Symbol模板](ui.md#symbol-row-template)的整行选择、缩进、状态与未读效果；明细及当日清仓保持原样；这些派生值不加入Total。regular 时段隐藏整列 Ext，包括列头、主行、明细和 Total 占位；取消该列排序并回收测量宽度。离开 regular 后恢复。使用已有服务端时段状态，不新增前端日历或请求。

- 主行单行，单元格上下 padding **3px**，适度压缩行间距；表格下方不单独画 Holdings/List 分割线，常规 List 列名位于自己的底部分割线上方。ticker 统一对齐，左侧独立保留展开箭头空隙；不增加副标题或主行 Trade Price。
- 当日建仓主行在ticker旁显示NEW，直接复用List的`symbol-flag new`样式与蓝色，规则由后端`is_new`提供；清仓行本身保持灰色，若当日建仓则NEW仍为共用蓝色。次日标记移除，不增加列或副行。
- Net Liq、P/L、P/L Day 和对应 Total 显示整数。P/L %、Chg% 使用一位小数；Ext 和成交价使用两位小数。
- Sold 显示整数百分比。零留空且无展开箭头；实际非零但四舍五入为零时显示 `<1%`，并允许展开。
- 缺失值显示 `—`；regular 时段的 Ext 整列隐藏。市值的价格来源、时段与时间，以及 P/L Day 基准保留 tooltip。
- P/L Day tooltip使用各批次服务端基准，区分entry price、previous regular close和mixed weighted basis；不能把全部批次标成上一收盘价。当日清仓注明realized today，Net Liq提示没有剩余仓位。

## Buy / Sold 明细

- 明细先 Buy 后 Sold，每笔单行，没有新增列头；明细跟随对应买入批次主行。
- 日期位于 Net Liq 列；股数位于 Sold 列并保留碎股；成交价位于 Chg% 列。
- Buy 的 Days/P/L 留空；Sold 保留持有天数与已实现盈亏。成交价来自既有成交金额除以股数，不受当前行情刷新影响。
- 报价与账户刷新保留展开状态，并更新实际变化的买卖明细。

## 排序、选择与状态

- 当前Regular启用状态时按服务端价格风险及量能离散rank优先，列头选定排序仅在相同rank内生效；其他时段沿用列头/默认顺序，不改账户数据。重排稳定性与方向优先级只在Intraday State需求维护。
- 列头只在降序/默认之间切换；换列替换当前排序。Symbol 按 Z–A；数值按原值，缺失/非有限值置后，同值稳定排序。排序只影响本页面显示，重开恢复默认。
- 当日清仓主行固定在所有余仓之后，主行/明细为灰色；任意排序及取消排序均不改变清仓相对顺序。信息正常显示、Sold为100%，仍可展开和选图，不新增标题或分组控件。Total P/L Day包含清仓日盈亏，其他余仓Total不含这些复盘记录；计算只在Holdings数据需求维护。
- 报价更新保留排序、选择和展开明细。仅顺序变化时保留既有行结构与焦点，不重新选图。
- 仅持仓主行显示 [Alert未读提醒](alert.md#统一未读提醒)，Holdings标题不显示该边框或闪烁。所有选图/当前图表更新统一标记symbol已读，灰线不受影响；未读收盘失效。未读快捷键、范围和导航规则只在 [List交互](list-interactions.md#未读-alert-导航) 维护。
- 点击和上下方向键选择现有图表对。同 ticker 的 Holdings 使用独立实时选择来源；名单刷新、筛选、折叠或删除同 ticker 不抢走持仓选择。
- 选中批次消失时改选首条持仓；再无持仓才回到名单。
- 刷新失败保留上次表格与成功时间；达到上述延迟门槛后时间显示为失败色，旁边出现可点击的圆圈感叹号，图形与暖黄色样式只在 [Logo / Icon](ui.md#操作与状态图标) 维护，与Chart数据警告共用绘制规则。尚无成功数据时错误入口直接可见；仅延迟但没有已知错误时不显示感叹号，不推断失败原因。
- 点击感叹号展开就地小面板，显示英文简短原因、下一步建议及可直接选中复制的脱敏原始消息，不自动弹出或抢焦点。再次点击、点击外部或Esc关闭；支持Enter/Space打开。重复刷新同一错误不关闭面板或重置详情文本选择，成功刷新后图标与面板自动清除。没有错误历史、通知、重启或手动重试按钮，不改变既有重试逻辑。
- 原因按后端错误阶段给出账户请求、交易匹配/数量校验、本地缓存保存三类建议；缺少阶段时显示通用刷新失败及交给Codex排查的建议。不把所有请求失败都断言成网络故障，也不建议靠重启修复交易归属。没有持仓和首次加载使用现有空表/加载状态，不改账户数据或名单归属。
